# Rashfa Theme Support

Official bilingual documentation website for the Rashfa Salla Theme.

Live site: https://mostafanajee-coder.github.io/rashfa-theme-support/

The site provides Arabic and English, RTL/LTR support, setup guidance, image recommendations, Service Hours guidance, responsive-design notes, FAQs, and public support contact details.

This repository contains documentation only. It does not contain the private theme source, credentials, customer data, or internal implementation details.
